Dashboard design overhaul
Rebuilt the visual layer with CSS custom properties, glassmorphism surfaces, and a proper 12-column bento grid. Added a time-aware hero greeting, staggered card entrance animations, and improved chart contrast.

Door schedules are now grouped by event
Previously, the same event appeared once per door — four identical "FLX Gym - Wednesday" rows for four doors. Now they collapse into a single entry with all doors listed. Much faster to scan.

Fixed invisible 30-day trend chart
The line chart in "Tickets - Last 30 Days" was silently failing because demo data was generated but never assigned to the chart state variable. Fixed the data pipeline and bumped grid / label contrast so the chart is readable against the dark card surfaces.
